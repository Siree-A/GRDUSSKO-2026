# GRDUSSKO 2026

เว็บสำหรับเก็บข้อมูลและสรุปผลโครงการจัดการความเสี่ยงด้านยาร้านชำ จังหวัดศรีสะเกษ

## ความสามารถ

- กรอกข้อมูล 4 รายงานสำหรับ 22 อำเภอ
- คำนวณคะแนนความเสี่ยง และจัดกลุ่มร้านชำอัตโนมัติ
- แสดง Dashboard สรุปผลแบบ dynamic
- เก็บข้อมูลในเบราว์เซอร์ และนำเข้า/ส่งออกเป็น JSON

## การใช้งาน

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ หรือ deploy ด้วย GitHub Pages

> ข้อมูลในเวอร์ชันนี้บันทึกใน Local Storage ของเบราว์เซอร์ จึงควรส่งออก JSON เพื่อสำรองข้อมูลเป็นระยะ
